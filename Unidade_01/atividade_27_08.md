# Atividade - 27/08 - Prompt Genérico x Prompt Estruturado

## Prompt genérico

**Pergunta:**

O que é Machine Learning?

**Resposta original:**

Machine Learning, ou aprendizado de máquina, é uma área da Inteligência Artificial que permite que computadores aprendam com dados e identifiquem padrões para realizar previsões ou tomar decisões sem que cada regra precise ser programada manualmente.

## Prompt estruturado

**Fórmula:** Papel + Objetivo + Contexto + Formato

**Prompt:**

- **Papel:** Aja como um professor de Ciência da Computação.
- **Objetivo:** Explique o que é Machine Learning.
- **Contexto:** A explicação será destinada a um iniciante que nunca estudou Inteligência Artificial.
- **Formato:** Explique de forma simples, usando exemplos do cotidiano e apresentando os principais conceitos em tópicos.

**Resposta original:**

Machine Learning, ou aprendizado de máquina, é uma área da Inteligência Artificial que permite que computadores aprendam a partir de dados para identificar padrões e tomar decisões.

Um exemplo simples é um aplicativo de e-mail que aprende a identificar mensagens de spam. Quanto mais exemplos de mensagens ele analisa, melhor consegue reconhecer características comuns de um e-mail indesejado.

**Principais conceitos:**

- **Dados:** informações usadas para o aprendizado.
- **Modelo:** sistema que identifica padrões nos dados.
- **Treinamento:** processo em que o modelo aprende com os dados.
- **Previsão:** resultado produzido pelo modelo a partir de novos dados.

## Comparação

O prompt genérico apenas faz uma pergunta, deixando para a IA decidir o nível de profundidade, o formato e a abordagem da resposta.

Já o prompt estruturado fornece instruções mais específicas sobre quem deve responder, o que deve ser explicado, para quem e de que maneira. Por isso, tende a produzir uma resposta mais adequada ao objetivo do usuário.

**Conclusão original:** quanto mais claro e estruturado for o prompt, maior tende a ser o controle sobre o resultado obtido.

A resposta do prompt estruturado foi mais útil, pois apresentou a explicação de forma organizada e adequada para um iniciante. A estrutura Papel + Objetivo + Contexto + Formato reduziu a ambiguidade porque deixou claro quem deveria responder, o que deveria ser explicado, para qual público e de que maneira. Assim, a resposta ficou mais direcionada, fácil de entender e com exemplos mais adequados ao objetivo.

## Comparação por critérios

| Critério | Prompt genérico | Prompt estruturado |
|---|---|---|
| **Papel** | Não define quem deve responder; a IA escolhe a abordagem. | Define o papel de professor de Ciência da Computação. |
| **Contexto** | Não informa o conhecimento prévio nem o público. | Especifica que a explicação é para alguém iniciante em Inteligência Artificial. |
| **Objetivo** | Pergunta o que é Machine Learning, sem detalhar o resultado esperado. | Pede uma explicação do conceito para apoiar a compreensão de um iniciante. |
| **Formato** | Não determina organização, linguagem ou exemplos. | Solicita linguagem simples, exemplos cotidianos e conceitos em tópicos. |
| **Restrições** | Não apresenta restrições explícitas. | Também não define limites de tamanho; orienta a simplicidade e o uso de exemplos e tópicos. |

**Síntese:** o prompt estruturado dá mais orientação sobre papel, contexto, objetivo e formato. Nenhum dos dois define uma restrição explícita de tamanho ou escopo; essa dimensão poderia ser especificada se fosse importante para a atividade.
